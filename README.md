# Intelligent Academic Decision Support System 

A futuristic AI-powered academic analytics dashboard designed to help students identify the most suitable engineering specialization based on their skills, interests, and academic strengths.

This project combines intelligent recommendation logic, performance prediction, prerequisite analysis, explainable analytics, and a premium cyberpunk-inspired user interface into a fully interactive web application.

## Features

* AI-Based Course Recommendation Engine
* Academic Risk Prediction
* Effort vs Outcome Analysis
* Monte Carlo Performance Estimation
* Prerequisite Gap Analysis
* Explainable AI Dashboard
* Interactive Skill Assessment
* Dynamic Recommendation Scoring
* Futuristic Cyberpunk UI/UX
* Fully Responsive Interface
* Advanced CSS Animations & Effects

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Glassmorphism UI
* Custom Animation System
* Dynamic DOM Manipulation

## Core Concepts Implemented

* Weighted Decision Scoring
* Recommendation Systems
* Explainable AI Concepts
* Monte Carlo Simulation
* Academic Risk Modeling
* Data Visualization Logic

## Purpose

Built as an advanced academic project demonstrating frontend engineering, intelligent recommendation systems, UI/UX design, and interactive analytics visualization.
